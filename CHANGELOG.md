## [Unreleased]

### Added

- Save open file tabs per git branch and restore them, in order and with the active tab focused, when switching back.
- Detect branch switches made outside VS Code, including while VS Code was closed.
- Keep current tabs when switching to a branch with no saved tabs.
- Prompt to save or discard unsaved files before tabs are swapped.
- Leave non-file tabs and files outside the repository open.
